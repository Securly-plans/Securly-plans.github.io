# EmeraldOS Lite 5.1.0 — Productivity Update

Adds Markdown Studio with live preview and My Files export, System Information with safe diagnostics export, and improves E.L.S.U.S. version tracking.

## Changes
- Added Markdown Studio with live preview, Markdown download, and save-to-My-Files support.
- Added System Information with local environment and workspace diagnostics export.
- Added launchers for the new apps to the desktop and Start menu.
- Updated Lite release/version metadata to 5.1.0.
- Preserves the existing encrypted workspace schema and existing apps.
