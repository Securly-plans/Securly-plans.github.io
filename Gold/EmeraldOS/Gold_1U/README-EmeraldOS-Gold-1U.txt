EmeraldOS Gold 1U

Install the Gold_1U folder beside other E.L.S.U.S. Gold folders. Gold 1U preserves the Gold 1U interface and features while adding private user separation, specific-file sharing, and per-app notification permissions.

For production privacy, read PRIVACY-AND-SHARING-DEPLOYMENT-1U.txt and deploy Firebase Authentication plus appropriate Firestore rules.
