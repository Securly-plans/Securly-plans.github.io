APPLICATION EDITOR COMPATIBILITY CHANGE
FILE: /Gold_1U/gold1u-features.js
FUNCTION: sandboxUserApp(app, options)
IFRAME SANDBOX: allow-scripts allow-forms allow-modals allow-downloads allow-same-origin
CACHE HANDLING: SAFE_CACHES wraps open, has, delete, keys, match, and individual cache methods in try/catch.
FALLBACK: blocked CacheStorage operations return undefined, false, an empty list, or a no-op cache instead of crashing the iframe application.
APP ACCESS: user code receives SAFE_CACHES as the caches variable and as api.cache.
