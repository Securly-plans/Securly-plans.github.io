EmeraldOS Gold 1J — Optional E.L.S.U.S. Root Shell Bridge

This folder is for the root E.L.S.U.S. shell, not the Gold_1J version folder.

1. Copy gold-shell-1j-bridge.js beside the root gold-shell.html file.
2. Add this immediately before </body> in gold-shell.html:

   <script src="gold-shell-1j-bridge.js"></script>

3. Give the operating-system iframe one of these identifiers:

   <iframe id="goldFrame" data-elsus-os></iframe>

The bridge also discovers #osFrame, #versionFrame, #emeraldOSFrame,
.gold-os-frame, or the first iframe when no explicit marker exists.

The bridge supports:
- Gold VM ready/acknowledgement handshakes
- Save-before-version-change
- Heartbeats and session status
- Open-app and navigation commands
- Theme and live Staff Control delivery
- Latest-manifest delivery and caching
- Safe iframe version switching

It NEVER writes Firestore system/emeraldGoldLatest. Publishing remains available
only through the verified Staff Edition Publisher Manager inside EmeraldOS Gold.
