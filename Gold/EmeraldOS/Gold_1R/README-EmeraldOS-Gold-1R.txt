EmeraldOS Gold 1R

Install the Gold_1R folder beside your other E.L.S.U.S.-compatible Gold folders. Do not rename the folder.

Gold 1R uses the same visual interface as Gold 1P. Its primary change is a universal, cloud-safe file system. Permanent deletion creates a deletion tombstone before the file record is removed. The tombstone is part of the version-independent cloud VM and prevents historical backups and earlier version categories from restoring the file.

Older backup-only files appear in Universal File System > Historical recovery candidates. They are not automatically placed back in active folders.
