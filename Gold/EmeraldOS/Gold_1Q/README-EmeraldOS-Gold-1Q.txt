Gold 1Q works with the original gold-shell.html and E.L.S.U.S. Shell V2. Shell V2 may identify the user's current route, but Gold 1Q retains its own login page and authentication session.

CLOUD VM CONTINUITY
Gold 1Q saves files, folders, settings, preferences, Registry data, mail, applications, custom logos, account history, game data, calendar events, update history, and workspace state to the version-independent Gold VM.

The migration gate reads Gold 1P and every earlier supported Gold format before cloud autosave is enabled. Same-ID files with different contents are preserved separately. Unknown file metadata is retained whenever possible.

PASSWORD SECURITY
Password changes require the current password. Gold 1Q stores a SHA-256 password hash and does not display, save, or log the password. Existing legacy plain-password fields are ignored after a hash is present.

ACCOUNT HISTORY
Settings includes a dedicated Account History page. History contains non-sensitive sign-in, password, update, and VM activity. It does not contain passwords or password hashes.

PUBLISHING POLICY
Gold 1Q never publishes on boot, login, setup, migration, update checking, Shell V2 routing, or query strings. system/emeraldGoldLatest is written only from Update Publisher Manager after Staff Edition verification, Emerald Mail verification, the publisher PIN, and clicking Publish this Version.
