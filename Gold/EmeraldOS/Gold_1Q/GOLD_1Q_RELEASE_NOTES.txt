EMERALDOS GOLD 1Q

REBUILT GOLD 1P USER INTERFACE
- Rebuilt from the established EmeraldOS Gold 1P visual foundation.
- Restores Gold 1P Start, taskbar, Quick Settings, Settings, window, toolbar, card, and application styling.
- Removes broad 1Q stylesheet overrides that could clash with unrelated applications.
- Scopes the new Calendar, games, password, and account-history styling to those applications only.
- Keeps the familiar Windows 10-inspired EmeraldOS Gold appearance.

BUILT-IN EMERALD GAMES
- Adds Emerald Games as a built-in game center.
- Adds Emerald Snake with a cloud-saved high score.
- Adds Emerald Mines with wins, game count, and best completion time.
- Adds Memory Match with saved wins, best move count, and best time.
- Game data migrates as part of the shared Gold cloud VM.

ACCOUNT SECURITY AND HISTORY
- Adds password changing for connected cloud accounts and local recovery accounts.
- Requires the current password before accepting a new password.
- Stores only SHA-256 password hashes; passwords are never logged.
- Adds Account History inside Settings.
- Shows login records, failed attempts on the current browser, password-change activity, update history, and general VM account logs.
- Supports JSON history export.

INTERACTIVE CALENDAR
- Adds month, week, and agenda views.
- Adds full event creation and editing with time, location, description, color, all-day mode, and reminders.
- Supports dragging events to another day.
- Adds event deletion and ICS calendar export.
- Migrates all previous Gold calendar event formats.

CLOUD VM AND COMPATIBILITY
- Preserves files, folders, settings, preferences, Registry data, mail, apps, custom logos, account history, game scores, and calendar data.
- Reads Gold 1P split-v1 and split-v2 schemas and every earlier supported Gold schema.
- Preserves conflicting files separately and blocks cloud autosave until migration validation succeeds.

PUBLISHING
- Gold 1Q does not auto-publish or auto-set system/emeraldGoldLatest.
- Publishing requires Staff Edition, Emerald Mail verification, the publisher PIN, and a direct Publish this Version click.
