EMERALDOS GOLD 1P

Complete standalone E.L.S.U.S.-compatible release folder.

INSTALLATION
Upload this folder as:

EmeraldOS/Gold_1P/

Gold 1P works with the original gold-shell.html and E.L.S.U.S. Shell V2. The version retains its own login page after Shell V2 identification and routing.

QUIET STARTUP AND UPDATES
- Startup events are recorded in Action Center without stacking banners.
- Gold 1P shows at most one optional noncritical startup summary.
- Critical security, account, emergency, migration, and failure alerts remain visible.
- An available update uses one prompt instead of showing both a prompt and duplicate toast.
- Update now, View details, and Later remain available.
- Notification behavior is configurable in Startup & Continuity.

PICK-UP-WHERE-YOU-LEFT-OFF CLOUD VM
Gold 1P saves a safe workspace session as part of the version-independent cloud VM. After migration validation it can restore:
- Safe open applications
- Window positions and sizes
- The active application
- Virtual desktop selection
- Display brightness and volume preferences
- Notification and update preferences

Sensitive Staff, publisher, password, setup, live-control, and temporary permission windows are not restored automatically.

MIGRATION AND COMPATIBILITY
Gold 1P reads Gold 1O split-cloud schemas and every earlier supported Gold schema. It preserves files, folders, settings, preferences, Registry data, mail, app data, custom logos, verified user apps, notes, tasks, events, contacts, tickets, update history, clipboard history, accessibility data, routines, backups, and session state.

Conflicting files are preserved separately. Identical duplicates are deduplicated. Cloud autosave remains blocked until local and cloud migration have completed and been validated.

QUICK SETTINGS AND UI
Quick Settings includes Focus Assist, Night Light, dark mode, transparency, quiet startup, update alerts, brightness, volume, connection status, update status, and direct Settings access. Gold 1P also improves narrow-window Settings layouts, toolbars, tables, cards, forms, taskbar spacing, toasts, and application overflow.

PUBLISHING POLICY
Gold 1P never publishes on boot, login, setup, migration, update checking, Shell V2 routing, or query strings. system/emeraldGoldLatest is written only from Update Publisher Manager after Staff Edition verification, Emerald Mail verification, the publisher PIN, and clicking Publish this Version.
