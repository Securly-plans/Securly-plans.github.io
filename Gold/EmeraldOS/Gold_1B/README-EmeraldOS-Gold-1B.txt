OS folder only. Built from EmeraldOS Gold 1A and compatible with the EmeraldOS Live Service Update System (E.L.S.U.S.).

Gold_1B/OS.html?publishLatest=1

New in Gold 1B:
- First-Boot Setup remains for brand-new users.
- Update Setup appears for users migrated from Gold 1A.
- Default desktop now shows only essential apps.
- Classic EmeraldOS right-click desktop menu is back.
- Right-click apps to pin/unpin from Start, taskbar, or desktop.
- Pin files to the desktop without moving them from Gold Explorer.
- Desktop Customizer app added for managing app pins, Start pins, taskbar pins, and pinned files.
- CSS added for the right-click menu, pinned taskbar apps, desktop file icons, and Update Setup.
- Retains Gold 1A app set, cloud VM behavior, E.L.S.U.S. compatibility, Staff Edition, Support, Gold Office, Appstore, and customization safety.
