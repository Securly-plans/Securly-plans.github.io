EmeraldOS Gold 1K

Install the complete Gold_1K folder beside the other E.L.S.U.S. Gold version folders.

E.L.S.U.S. Service Pack One is the official name for the shell, Staff Center, live staff-control, verified user-app, custom-logo, session, and save-before-version-switch improvements introduced in Gold 1J and retained in Gold 1K. It is not a secondary product name.

ACTIVE UPDATE NOTIFICATIONS
Gold 1K reads system/emeraldGoldLatest and can immediately notify the user when staff publishes a newer release. The user must choose Update now. Later snoozes the prompt. Gold 1K does not apply updates automatically.

PUBLISHING SAFETY
Only Update Publisher Manager writes system/emeraldGoldLatest. A verified Staff Edition session, Emerald Mail verification, the publisher PIN, and clicking Publish this Version are all required.

SHELL PATCH
The optional ELSUS_ROOT_PATCH folder contains the Service Pack One-compatible root-shell bridge. Add its script to the root gold-shell.html page.
