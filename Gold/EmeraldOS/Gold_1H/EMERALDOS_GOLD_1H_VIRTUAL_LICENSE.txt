EmeraldOS Gold 1H Virtual License

Product: EmeraldOS Gold 1H
Folder: Gold_1H
Update Service: EmeraldOS Live Service Update System (E.L.S.U.S.)
Terms of Service: https://securly-plans.github.io/TOS.html

This virtual license is shown during First-Boot Setup. First-Boot Setup is completed once per signed-in user across the compatible E.L.S.U.S. Gold version line. Existing users receive Gold 1H Update Setup instead, and their version-independent cloud VM remains under:

emeraldOSUsers/{username}/goldVM/current

EmeraldOS Gold may store preferences, files, application data, mail, registry values, support tickets, update choices, workspace state, and recovery information locally and, when Firebase is configured, in cloud storage.

The Emerald Registry Editor changes only the EmeraldOS virtual registry. It cannot access or modify the host computer's Windows Registry.

Staff-only applications require Gold Staff Edition verification. Publishing Gold 1H requires a verified Staff Edition session, the Update Publisher Manager, the correct publisher PIN, and clicking Publish this Version. Gold 1H does not publish itself during boot, First-Boot Setup, Update Setup, or through query strings.

User applications can affect VM data. Install only applications you trust.
