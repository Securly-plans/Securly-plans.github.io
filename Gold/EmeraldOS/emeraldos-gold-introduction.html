What it includes

A desktop built around continuity, control, and useful tools.

EmeraldOS Gold combines an evolving application environment with cloud-based personalization and a dedicated update system that keeps users connected to the correct release.

Cloud VM continuity

Your desktop, preferences, files, and supported application data are designed to move with your EmeraldOS account.

Dynamic updates

E.L.S.U.S. and the Gold Shell route users to their active version and provide optional update prompts when a newer release is published.

Built-in applications

Productivity, utilities, customization, communication, games, and web tools are presented through a unified desktop experience.

Personalization

Adjust appearance, desktop behavior, accessibility, startup preferences, and other supported user settings to fit your workflow.

Communication tools

Current and future releases can include built-in messaging, mail, and live communication features across the Emerald ecosystem.

Optional staff support

Supported versions may allow users to request staff assistance, including live desktop viewing or control with the user’s permission.

EmeraldOS Live Service Update System

E.L.S.U.S. keeps every user on the right Gold release.

The Gold Shell checks the user’s current version and directs them to that release. When a newer version is available, users may be prompted to update. Updating is optional but recommended, and rollback support may be available in a limited capacity.
