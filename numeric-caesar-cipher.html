Numeric Caesar Cipher

Select a key from A through F. Letters are shifted, then converted using A=26, B=25, C=24 … Z=1.

Encoding shifts forward. Decoding shifts backward using the same key.

Encoding format
  • Letters become numbers from 1 through 26.
  • A normal space becomes /.
  • A line break becomes //.
  • Numbers and punctuation are safely stored as literal tokens beginning with ~.

Example with key A: ABC shifts to BCD, then becomes 25 24 23.

Runs entirely in the browser. No server or external library is required.
