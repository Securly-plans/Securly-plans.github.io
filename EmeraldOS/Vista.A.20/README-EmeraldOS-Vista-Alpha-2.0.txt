EmeraldOS Vista Alpha 2.0
==========================

EmeraldOS Vista is now treated as its own EmeraldOS product line.
This package is based on EmeraldOS 5.7 and adds a separate Vista-inspired glass shell layer.

Important: this is an original Vista-inspired EmeraldOS design. It does not include Microsoft logos, icons, wallpapers, sounds, or copied Windows assets.

Product line features
---------------------
- EmeraldOS Vista Alpha 2.0 product identity
- Vista Hub desktop icon
- Glass desktop, taskbar, Start menu, and windows
- Vista-style Control Panel
- Vista Welcome Center
- Vista Personalization
- Gadget Gallery
- Network and Sharing Center
- Security Center
- Media Center
- Photo Gallery placeholder
- Product Line roadmap panel
- Sidebar gadgets: clock, account, cloud status, quick access
- Keyboard shortcuts:
  - Ctrl + Alt + V opens Vista Hub
  - Ctrl + Alt + P opens Personalization

Included EmeraldOS platform features
------------------------------------
This package keeps the EmeraldOS 5.7 base platform, including:
- Emerald Assistant
- Application Editor
- Creator Platform
- User Appstore
- Emerald Office
- Emerald Mail
- Files
- Chat
- moderation tools
- administrative tools

Upload instructions
-------------------
Upload the full folder to GitHub Pages. OS.html loads:

<link rel="stylesheet" href="emerald-vista.css">
<script src="emerald-vista.js"></script>

Keep firebase-config.js and firebase.js in the same folder so cloud features continue working.
