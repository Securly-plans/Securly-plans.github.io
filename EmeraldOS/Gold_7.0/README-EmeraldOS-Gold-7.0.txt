EmeraldOS Gold 7.0
===================

Built from EmeraldOS Gold 6.0 with Win10-inspired support and emergency improvements.

Main additions:
- Emergency Center for urgent tickets, Quick Assist, emergency snapshots, Safe Mode, diagnostics, and window repair.
- Quick Assist app with visible user-approved remote help.
- Troubleshooters for login, Office, Store, files, remote assistance, and performance.
- Reliability Monitor for support events, tickets, emergency logs, remote sessions, and notifications.
- Recovery Options app for VM restore, backup, Safe Mode, and desktop reset.
- EmeraldOS Welcome app with stronger EmeraldOS Gold branding.
- Emerald BIOS A5 with EMERGENCY, QUICKASSIST, RECOVERY, and RELIABILITY DOS commands.
- More Windows 10-inspired UI styling for taskbar, Start, windows, cards, and support surfaces.
- Improved independent SVG app logos.
