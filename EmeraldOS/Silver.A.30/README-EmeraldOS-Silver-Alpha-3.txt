What changed in Silver Alpha Version 3
--------------------------------------
- Separate EmeraldOS Silver product-line identity.
- Silver Center desktop hub.
- Silver Apps desktop folder-style launcher.
- Silver Desk daily dashboard.
- Silver Control Center.
- Silver Files, Office, Mail, Chat, People, Media, Gallery, Assistant, App Market, Creator Studio, Security, Network, Personalization, Recovery, Updates, Help, and Feedback front ends.
- Built-in Silver Notes, Silver Tasks, and Silver Journal.
- Silver taskbar notification bell.
- Silver sidebar gadgets for clock, account, notifications, and quick access.
- Better Silver Start menu links.
- Cleaner silver/glass windows, taskbar, desktop icons, and panels.

Platform compatibility
----------------------
The Silver shell keeps EmeraldOS platform services underneath, including Emerald Assistant, User Appstore, Application Editor, Emerald Office, Emerald Mail, Files, Chat, and admin/moderation tools.

Design policy
-------------
This is an original EmeraldOS Silver design. It does not include Microsoft logos, Windows icons, Windows wallpapers, Windows sounds, or copied Microsoft assets.
