EmeraldOS Advanced 10 - Independent Model

This is an independent Windows 10-inspired EmeraldOS model. It is separate from the EmeraldOS Silver line and does not depend on silver-advanced10.js, silver-beta files, or the Silver shell.

Main files:
- OS.html
- advanced10.css
- advanced10.js
- firebase.js
- firebase-config.js
- index.html
- register.html
- loading.html
- bios.html
- plans.html

Included features:
- Independent Advanced 10 product identity
- Windows 10-inspired original UI
- Dark modern taskbar
- Square Start button
- Start menu with app list and pinned tiles
- Search panel
- Task View
- Action Center
- Widgets panel
- Modern Settings app
- Classic Control Panel
- File Explorer with folders, files, rename, star, trash, restore, preview, and download
- Advanced Office with Docs, Sheets, Slides, Forms, templates, save/export logic
- Advanced Mail with inbox, sent, drafts, trash, compose, reply, unread support
- Advanced Chat with rooms and messages
- People app with contacts, favorites, and blocking
- Store and Creator Studio with user apps and warning
- Security Center
- Device Link
- Update Center
- Media Center
- Timeline
- Restore Center with local backup/export/import and Firebase save/restore

Cloud restore path:
emeraldOSUsers/{username}/advanced10Independent/current

Important:
This build is Windows 10-inspired only. It does not include Microsoft logos, Windows icons, Microsoft wallpapers, Microsoft sounds, or copied Microsoft assets.
