EmeraldOS 4.3 - System & Input Update

This build is based on EmeraldOS 4.2.6 and keeps the 40_ localStorage prefix for EmeraldOS 4.x compatibility.

New in 4.3:
- More system settings and a new System Control Center.
- Expanded Display Settings: theme, icon size, grid snap, seconds on clock, reduced animations, compact taskbar.
- Keyboard & Mouse Settings: pointer speed preference, double-click speed, repeat speed, shortcut enable/disable, visual mouse button swap flag.
- Controller Center using the browser Gamepad API where supported.
- More keyboard shortcuts, including Ctrl+Alt+S, Ctrl+Alt+D, Ctrl+Alt+K, Ctrl+Alt+C, Ctrl+Alt+F, Ctrl+Alt+T, Ctrl+Alt+P, Ctrl+Alt+R, Ctrl+Space, Ctrl+Shift+Esc, Alt+F4, and Esc.
- More inclusive Win95 right-click menu with app, desktop, input, display, pinning, repair, and system actions.
- Desktop Repair app to refresh, snap, reset, repair folders, clear session, and request sync.
- More applications: System Control Center, Display Settings, Keyboard & Mouse, Controller Center, Shortcut Manager, Desktop Repair, Accessibility, Sound Settings, Power Options, App Permissions, Update Center, Device Hub, Input Diagnostics, Shortcut Console, Registry Tweaks, Admin Policy Center, Fleet Settings.
- More terminal commands: settings, display, input, controller/gamepad, shortcuts, desktop.repair, desktop.snap, desktop.grid on/off, build.

Upload all files into the same EmeraldOS folder. Keep your existing firebase.js in the folder. If using Firebase Storage, keep cors.json and your bucket CORS setup from 4.2.6.
