EmeraldOS is Emerald Systems newest project.

It is a vitural machine that in later versions will be able to support other possible projects such as a functional proxy browser.

The current base version of EmeraldOS is V3.0, it includes a Cloud Storage System (Files), Docs, Notes, Games (Currently Emerald Games), Chat (Currently Iridium Chat), and a Multimedia Player.
There is also a user system, the base model is currently free-to-use and free-to-register.

This project is intended to boost Emerald Systems Services popularity.
