TestOS 3.2.T.4 - Economy App Folders Build

Built on the independent Test-OS package.

New in 3.2.T.4:
- New Economy edition below Home.
- Edition order: Economy -> Home -> Business -> Virtue -> Developer -> Executive.
- Applications are stored visually in desktop app folders instead of one giant desktop list.
- Locked edition apps stay hidden from desktop and Start menu.
- More applications across all editions.
- Extra terminal commands: appfolders, folder.open, edition.level, build, registry.find, registry.roots, desktop.sync, package.list, package.info.
- Extra registry defaults under HKEY_CURRENT_USER and HKEY_LOCAL_MACHINE.
- Desktop folder icon layout uses the existing Firebase-backed desktop layout sync.

Install:
1. Rename this folder to Test-OS if you want it as your live Test-OS folder.
2. Copy your existing firebase.js into this folder.
3. Upload the folder to EmeraldOS/Test-OS on GitHub Pages.
4. Open https://securly-plans.github.io/EmeraldOS/Test-OS/
