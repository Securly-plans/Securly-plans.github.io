EmeraldOS Silver Advanced
=========================

EmeraldOS Silver Advanced is a separate Silver product-line model built as an Aero-modern desktop experience inspired by Windows 7/10 design patterns while using only original EmeraldOS/Silver assets.

Included files:
- OS.html
- silver-advanced.css
- silver-advanced.js
- os.js
- os.css
- emerald57.js
- cloudstorage.js
- firebase.js
- firebase-config.js
- bios.html
- loading.html
- plans.html
- index.html
- register.html

Major features:
- Separate Silver Advanced identity and boot flow.
- Aero-modern desktop shell with glass/acrylic style taskbar, windows, Start menu, and app logos.
- Consolidated app model focused around larger hubs instead of many scattered small apps.
- Advanced Home dashboard.
- Silver Explorer for Drive/files, recent, starred, trash, preview, rename, star, restore, and delete forever.
- Silver Office with Docs, Sheets, Slides, Forms, Templates, and Vault-like Drive integration.
- Silver Mail with inbox, sent, drafts, trash, compose, read, reply, and unread support.
- People, contacts, blocking, and mail actions.
- Action Center with universal notifications and taskbar unread badge.
- Advanced Search for apps, files, and contacts.
- Task View for recent/restorable apps.
- Restore Center with local and Firebase-backed cloud workspace save/restore.
- Settings, Control Panel, Security Center, Creator Studio, Silver Store, Media Center, and Help.
- Responsive layout for smaller screens and larger desktops.

Cloud restore path:
emeraldOSUsers/{username}/silverAdvanced/current

Notes:
- This build keeps the EmeraldOS 5.7 platform files for compatibility, but the user-facing shell is EmeraldOS Silver Advanced.
- This is inspired by the general glass/modern desktop concepts of Windows 7/10, but does not include Microsoft logos, Windows icons, Windows wallpapers, Windows sounds, or copied Microsoft assets.
- Upload the whole folder together. OS.html loads silver-advanced.css and silver-advanced.js.
