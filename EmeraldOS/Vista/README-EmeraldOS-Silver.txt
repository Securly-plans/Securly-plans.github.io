EmeraldOS Silver
Vista-Inspired Design Package

This package is based on the EmeraldOS 5.7 build and adds a new Silver interface layer.
It is inspired by the general glass-style desktop design era, but it does not include Microsoft logos, icons, wallpapers, or copied assets.

Included:
- OS.html updated to load the Silver design layer
- emerald-silver.css
- emerald-silver.js
- Existing EmeraldOS 5.7 core files
- Emerald Assistant, Creator Platform, Emerald Office, and Emerald Mail remain included

Design features:
- Silver-blue gradient desktop
- Glass-style rounded windows
- Translucent taskbar
- Orb-style Emerald start button
- Larger glossy Start menu
- Sidebar gadgets for clock, user status, and quick access
- Cleaner form fields, taskbar buttons, notifications, menus, and panels
- Silver Welcome Center
- Silver Personalization window

Files added:
- emerald-silver.css
- emerald-silver.js

Important upload note:
Upload the full folder so OS.html can load:
<script type="module" src="os.js"></script>
<script type="module" src="emerald57.js"></script>
<link rel="stylesheet" href="emerald-silver.css">
<script src="emerald-silver.js"></script>

Shortcut:
Ctrl + Alt + S opens the EmeraldOS Silver Welcome Center.

Firebase:
The included firebase-config.js and firebase.js are copied from the existing 5.7 package.
If your live site already has working Firebase files, keep using those if they are newer.
