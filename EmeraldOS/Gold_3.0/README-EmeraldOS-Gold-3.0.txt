EmeraldOS Gold 3.0
Professional Support, Cloud Desktop, Staff Control, Office, and User Experience Update

Built from the full Gold 1.4 / 2.0.1 branch so the existing app set, login flow, Staff Edition, support tools, remote assistance, logos, BIOS, and desktop features are retained.

Main upgrades:
- Gold Office 3.0 with improved Docs, Sheets, Slides, Forms, Templates, Recent, and Vault.
- Gold Docs: headings, font size, bold, italic, underline, strike, bullets, numbered lists, alignment, text color, highlight, insert date, insert table, word count, HTML export, TXT export, and print.
- Gold Sheets: add rows, add columns, auto total, CSV export, and formula preview for SUM, AVG, COUNT, MIN, and MAX ranges.
- Gold Slides: themes, multiple slides, present mode, and HTML export.
- Gold Forms: short answer, paragraph, choice, checkbox, date, form preview, and save.
- Support Center 3.0 with ticket categories, priority, diagnostics attachment, and optional remote assistance request.
- Staff Console retains staff-only access, ticket review, staff replies, live remote desktop view, and visible remote commands.
- Added Help, Diagnostics, Keyboard Shortcuts, and Safe Mode apps.
- Settings 3.0 sections include System, Devices, Network & Internet, Personalization, Apps, Accounts, Time & Language, Accessibility, Search, Privacy, Update & Security, Support, Staff Edition, BIOS & DOS.
- Emerald Systems BIOS A2 and Emerald DOS wording updated.
- More Windows 10-inspired Gold UI polish.
- New EmeraldOS Gold 3.0 logo and app logos for added apps.

Deployment:
