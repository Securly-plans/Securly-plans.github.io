Choose Your EmeraldOS Edition

EmeraldOS 5.1: uses Virtue as the default edition, keeps desktop app folders, uses 40_ storage keys, and restricts Developer to verified Emerald Games mods/admins and Executive to verified Emerald Games administrators.

Application Folder Layout

Essential Apps
Economy apps such as Files, Notes, Calculator, Clock, System, Plans, Help Center, Scratch Pad, and Unit Converter.
Personal Apps
Home apps such as Docs, Calendar, Journal, and Reminder Board.
Business Apps
Workspace, Browser, App Store, Chat, Media Player, Reports, Planner, Invoices, and Presentations.
Creative Apps
Paint, Theme Lab, Icon Studio, Color Mixer, Font Book, Audio Notes, and Archive Manager.
Developer Apps
Terminal, Registry Editor, Code Studio, Script Lab, JSON Studio, API Tester, Network Tools, and Package Manager.
Executive Apps
Executive Dashboard, Deployment Center, License Manager, Policy Manager, Audit Center, and Games.
Edition order: Economy → Home → Business → Virtue → Developer → Executive

Default edition: Virtue. Higher editions include visible features from lower editions. Locked apps are hidden from the desktop and Start menu. Developer requires Emerald Games mod/admin verification from BIOS. Executive requires Emerald Games admin verification from BIOS.
