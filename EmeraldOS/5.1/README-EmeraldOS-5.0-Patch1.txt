EmeraldOS 5.0 Patch 1 - Text Fields & Word Processor Update

This patch is based on EmeraldOS 5.0 Major Release.

Main fixes:
- Fixed broken text fields caused by the 5.0 desktop selection cleanup blurring active fields.
- Restored reliable typing/clicking in inputs, textareas, selectors, and contenteditable editors.
- Added stronger CSS rules for editable controls inside OS windows.

Word processor improvements:
- Added Emerald Writer Pro.
- Added rich editing toolbar: bold, italic, underline, bullets, numbering, alignment, headings, font size, text color.
- Added templates: letter, memo, policy.
- Added find/replace.
- Added insert date and signature.
- Added autosave.
- Added word/character count.
- Added export to .txt and .html.
- Added improved Document Vault with open/delete support.

Terminal additions:
- writer
- word
- writerpro
- office
- emeraldoffice
- vault
- doc.vault

Important:
- Keep your existing firebase.js in this same folder.
- This continues to use the 40_ storage prefix for EmeraldOS 4.x/5.x compatibility.
