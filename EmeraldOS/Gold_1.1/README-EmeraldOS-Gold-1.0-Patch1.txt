EmeraldOS Gold 1.0 Patch 1
Experience, Settings, Restore, BIOS F12 and App Logic Fixes

This package is a full drop-in replacement for EmeraldOS Gold 1.0.

Main fixes and improvements:
- Lighter Windows 10-inspired original EmeraldOS Gold UI.
- Press F12 during startup/loading to open Emerald Systems BIOS A1 / Emerald DOS.
- Added an in-OS Emerald DOS app.
- Improved Settings with working sections for System, Personalization, Apps, Accounts, Time, Accessibility, Privacy, Update/Security, and BIOS/DOS.
- Added better first-boot setup controls.
- Added better restore logic that saves a fuller local workspace and can restore from Firebase when firebase.js works.
- Added patch apps: Gold Setup, Personalization, Display, Sticky Notes, Gold To Do, Snip Board, Voice Recorder, Emerald DOS, and Gold Tips.
- Added taskbar/start/desktop UI polish and responsive layout improvements.
- Added local logic for Sticky Notes, To Do, Snip Board, Voice Recorder notes, and DOS commands.

Important files:
- OS.html
- gold10.js
- gold10.css
- gold10-patch1.js
- gold10-patch1.css
- bios.html
- loading.html
- index.html
- firebase.js
- firebase-config.js

Startup BIOS / DOS:
- Press F12 on loading.html or early OS startup.
- Or open bios.html directly.
- Or open Settings -> BIOS & DOS.

Cloud restore path:
emeraldOSUsers/{username}/gold10/current

This UI is Windows 10-inspired only. It uses original EmeraldOS styling, logos, and assets.
