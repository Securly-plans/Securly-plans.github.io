EmeraldOS Gold 5.0
===================

EmeraldOS Gold 5.0 is a Windows 10-inspired browser-based VM desktop update built from the Gold 4.0 branch.

Major updates:
- User registration remains included through register.html.
- Login is required before opening OS.html.
- Gold VM workspace continuity remains included with local save/restore and Firebase sync attempts.
- Emerald Systems BIOS A4 has been rebuilt with a modern firmware screen and expanded Emerald DOS commands.
- User Appstore now supports JS-only app uploads and packaged HTML/CSS/JS .egoldapp.json uploads.
- Gold App Lab lets users build, preview, submit, and export JS or HTML/CSS/JS apps.
- App Packager imports .js, .json, and .egoldapp.json files.
- Packaged apps run in a sandboxed iframe.
- Accessibility Center adds text scale, high contrast, extra borders, readable font, reduced motion, large cursor, focus rings, underlined controls, color filters, and Focus Assist.
- Theme Studio adds background color, background image upload, background URL, background mode, accent color, Start layout, taskbar size, and window transparency.
- Added Windows 10-inspired apps: Gold Browser, Gold Terminal, Media Player, Control Panel, Snip & Sketch, System Information, Theme Studio, Accessibility Center, App Lab, and App Packager.
- Added more EmeraldOS Gold branding and app logos.
- Added minor UI polish for taskbar, windows, settings, store, developer tools, and accessibility.

Startup shortcuts:
F12 = Emerald Systems BIOS A4 / Emerald DOS
F9  = Gold Staff Edition
F1  = Support Center

Expanded BIOS / DOS commands:
HELP, VER, DIR, APPS, USERS, WHOAMI, LOGIN, REGISTER, LOGOUT, BOOT, DESKTOP, SAFE, SETUP, STAFF, SUPPORT, STORE, DEV, OFFICE, EXPLORER, SNAPSHOT, RESTORE, BACKUP, RESET, DIAG, PREFS, THEME, ACCESSIBILITY, COLOR, BG, CLEARCACHE, TIME, DATE, MEM, ECHO, CLEAR, EXIT
