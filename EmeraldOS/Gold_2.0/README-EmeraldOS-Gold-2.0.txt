EmeraldOS Gold 2.0 — Rebuilt from Gold 1.4

This package is the corrected EmeraldOS Gold 2.0 line. It is built from the full Gold 1.4 feature set instead of the reduced 2.0 branch.

Included:
- Normal EmeraldOS Gold login required before desktop access.
- Staff tools remain staff-only.
- Full Gold 1.4 app set retained.
- Independent SVG app logos included in app-logos/.
- Added taskbar, Start menu, and Settings logout.
- Improved support and remote assistance flow.
- Staff can view a live-updating remote desktop snapshot after the user requests help and grants control.
- Staff can send visible remote commands: open apps, tile/cascade windows, close all windows, save workspace, send messages, and end control.
- User sees a remote-control banner and can end control at any time.

Upload the whole folder. OS.html loads gold20.css and gold20.js.

Startup shortcuts:
F12 = Emerald Systems BIOS A1 / Emerald DOS
F9  = Gold Staff Edition
F1  = Support Center
