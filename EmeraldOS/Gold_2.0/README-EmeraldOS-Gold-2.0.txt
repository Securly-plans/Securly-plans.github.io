EmeraldOS Gold 2.0
====================

Gold 2.0 focuses on support, user friendliness, Gold Store trust, logout, and staff tools.

Included:
- Login-required OS boot
- Logout from Start, taskbar, and Settings
- Improved Support Center with tickets and replies
- Remote Assistance request + live desktop state publishing
- Staff-only Staff Center and staff.html console
- Gold Store 2.0 with Staff Verified badges
- Staff tools for verifying and staff-installing apps
- Improved Settings and Personalization
- Windows 10-inspired EmeraldOS Gold interface
- Independent SVG logos for built-in apps
- Emerald Systems BIOS A1 with Emerald DOS

Startup shortcuts:
- F12: BIOS / Emerald DOS
- F9: Staff Edition
- F1: Support Center

Main files:
- OS.html
- gold20.css
- gold20.js
- index.html
- loading.html
- bios.html
- staff.html
- app-logos/

Notes:
Staff and Firebase-backed features require Firestore rules that allow the intended staff reads/writes.
The static web build also keeps localStorage fallback data so the UI can be tested on GitHub Pages.
