EmeraldOS Gold 6.0
====================

This build is based on EmeraldOS Gold 5.0 and focuses on personalization, Staff Edition resources, Support Center improvements, unique app purposes, Emerald BIOS A4, and Windows 10-inspired user friendliness.

Main files:
- OS.html
- index.html
- register.html
- loading.html
- bios.html
- staff.html
- gold60.js
- gold60.css
- firebase.js
- firebase-config.js
- emerald-gold-60-logo.svg
- app-logos/

Gold 6.0 changes:
- Expanded personalization with gradients, solid background color, wallpaper URL/upload, taskbar opacity, top/bottom taskbar, Start width, Mica blur, secondary accent, desktop density, and icon sizing.
- Reduced duplicate-purpose apps by consolidating app roles:
  * Settings = central system hub
  * Theme Studio = visual personalization
  * Accessibility Center = accessibility only
  * Gold App Lab = app building
  * App Packager = import/export/packaging
  * User Appstore = install/upload/run apps
- Expanded Staff Edition resources:
  * Staff Resources
  * Staff Knowledge Base
  * Staff Reports
  * Staff Broadcast
  * Remote Desk
- Improved Support Center with templates, guided remote assistance, resources, diagnostics, and ticket tracking.
- Keeps login, registration, cloud VM workspace saving, Staff Edition, Gold Office, User Appstore, App Lab, packaged app support, remote assistance, and BIOS features from 5.0.
- Updates branding to EmeraldOS Gold 6.0 / Emerald BIOS A4.

Startup shortcuts:
- F12 = Emerald BIOS A4 / Emerald DOS
- F9 = Gold Staff Edition
- F1 = Support Center
- Ctrl + Alt + L = Log out

Upload the full folder to your Gold_6.0 deployment directory.
