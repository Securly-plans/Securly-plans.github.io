EmeraldOS Gold 8.0

Gold 8.0 rebuilds EmeraldOS Gold around a setup-once cloud virtual machine experience.

Highlights:
- Login required before desktop access.
- User registration retained.
- Full VM state save/restore using Firebase when available.
- Cloud path: emeraldOSUsers/{username}/gold8/current.
- Tracks preferences, files, tickets, mail, notes, tasks, contacts, notifications, user apps, remote sessions, emergency logs, snapshots, and workspace data.
- Improved first-boot setup wizard.
- More customizable desktop, taskbar, Start menu, icons, backgrounds, colors, opacity, blur, fonts, accessibility, and cloud sync.
- Emerald BIOS A6 with expanded Emerald DOS cloud commands.
- Retains Gold Office, Support, Staff Edition, Quick Assist, Emergency Center, User Appstore, App Lab, App Packager, VM Center, Theme Studio, Accessibility Center, and previous Gold 7.0 apps.
- Better Gold 8 logo and refreshed app logos.
